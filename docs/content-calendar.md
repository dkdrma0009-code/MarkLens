# MarkLens 인스타·스레드 콘텐츠 캘린더

> 매일 "뭐 올리지" 고민을 없애는 틀. 유형을 요일에 고정해두고 돌린다.
> 전 채널 공통 원칙: **인스타는 도달, 뉴스레터는 소유.** 모든 콘텐츠의 최종 목적지는 뉴스레터 구독.

## 콘텐츠 3종 (제작 경로)

| 유형 | 빈도 | 만드는 법 | 저장/공유 유발 |
|---|---|---|---|
| ① 트렌드 카드 | 주 3~4 | `/admin/cardnews` → 인사이트 1건 "생성" | 마지막 장 "면접에서 이렇게" 실전 팁 |
| ② 사례 카드 | 주 2 | `/admin/cardnews` → 라이브러리(해외 캠페인) 인사이트 "생성" | 의외성("육아를 MMA로?") → 친구 태그 |
| ③ 용어·꿀팁 카드 | 주 1~2 | `/admin/cardnews` → "용어카드 만들기" 입력 | 취준생 기본기 → "외워둬야지" 저장 |

모두 카드뉴스 자동 생성 → 편집 다듬기 → 다운로드 → 인스타/스레드 업로드.
첫 장은 후킹 공식(궁금증·의외성·위기감·숫자)이 자동 적용됨.

## 2주 캘린더 (예시 — 요일 고정)

| 요일 | 유형 | 비고 |
|---|---|---|
| **월** | 트렌드 카드 | 뉴스레터 발행일 → "이번 주 알아야 할 트렌드" 톤, 뉴스레터 구독 유도 |
| 화 | 용어·꿀팁 카드 | 가벼운 기본기. 만들기 쉬움 |
| 수 | 사례 카드 | 해외 캠페인 스토리. 가장 잘 터지는 유형 |
| 목 | 트렌드 카드 | |
| 금 | 사례 카드 | 주말 전 공유 잘 됨 |
| 토 | 릴스 (선택) | 카드뉴스 이미지 → 인스타 사진+음악 슬라이드쇼 (편집 0) |
| 일 | 휴식 / 트렌드 카드 | 부담되면 쉬기 |

2주차도 동일 패턴 반복. 막히면 이 표대로만 채우면 됨.

## 릴스 — 2트랙

**인기 오디오와 API 자동발행은 양립하지 않는다.** 이게 트랙을 나누는 이유다.
Graph API로 발행하면 음원이 영상에 미리 구워져 있어야 하고, 인스타 음원
라이브러리의 트렌딩 사운드는 붙일 수 없다(라이선스가 인앱 사용 기준). Audio API가
있긴 하나 3자 상업 배포가 허가된 트랙만 반환해서 트렌딩 사운드는 대체로 없다.

게다가 인기 오디오의 도달 효과는 **그 오디오 페이지에 내 릴스가 묶이는 것**에서
나온다. 같은 노래를 파일에 구워넣어도 그 연결이 안 생기므로 효과가 없다.
소리가 같아도 알고리즘상으론 남남이다.

| | 자동 트랙 | 수동 트랙 |
|---|---|---|
| 빈도 | 주 3~4 (카드뉴스와 함께) | 주 1 (토) |
| 발행 | 어드민 → 🎞 릴스컷 → 릴스 발행 | 인스타 앱 |
| 오디오 | 영상에 구운 것만 (현재 **무음**) | **인기 오디오** |
| 목적 | 꾸준한 노출·계정 주제 학습 | 도달 스파이크 |

### 자동 트랙 — 🎞 릴스컷

`/admin/cardnews` → 행의 `🎞 릴스컷` → 렌더 완료 후 다운로드 또는 릴스 발행.

카드뉴스 6장 중 **cover·why·apply·cta 4장만** 쓴다(약 9.6초). fact·keywords는
읽는 콘텐츠라 정지 화면이 필요한데, 릴스에서 정지는 스크롤을 부른다. 정보 나열은
카드뉴스가 맡고 릴스는 후킹→의미→실전→구독만 태운다. 장면 전체에 켄번즈 연속
줌이 걸려 멈추는 구간이 없다.

⚠️ **현재 무음이다.** 무음 릴스는 도달이 나쁘다. 로열티프리 BGM을 넣는 게
가장 임팩트 큰 다음 작업이다.

### 수동 트랙 — 편집 없이 (주 1회)

1. 이미 만든 카드뉴스 이미지 6장을 준비
2. 인스타 릴스 → 사진 여러 장 선택 → 배경음악 추가 (인스타 자체 기능)
3. 끝. 편집 0, 릴스 도달(피드보다 넓음) 획득.

자동 트랙이 생겼어도 이걸 없애면 안 된다. 인기 오디오 레버는 여기서만 작동한다.

## 첫 장 후킹 공식 (자동 적용됨 — 참고용)

카드뉴스 생성 시 첫 장이 아래 중 하나로 자동 생성됨:
- 궁금증: "왜 ~했을까?"
- 의외성·반전: "육아를 MMA로?"
- 위기감·결핍: "이거 모르면 면접서 막힘"
- 구체 숫자: "마케터 90%가 놓친"

금지: 정보 나열("구글 마케팅 라이브 요약"), 싸구려 낚시("충격/대박").

## bio (유입 → 구독 전환)

```
취준생·주니어 마케터를 위한 글로벌 마케팅 트렌드
면접·포트폴리오에 바로 쓰는 인사이트 ↓
📩 매주 월요일 무료 뉴스레터 (+ 면접질문 40선 PDF)
🔗 marklens.site/ig
```
링크는 반드시 **marklens.site/ig** — 구독 페이지 직행 + 인스타 유입 UTM 추적. 팔로워를 이메일 구독자로 전환하는 게 핵심.

## 캡션 (저장·공유가 도달을 결정)

캡션은 자동 생성되며 마지막에 **저장·공유 유도 한 줄**이 들어감 ("면접에서 써먹고 싶으면 저장 📌 / 친구 태그 👀").
정보 카드뉴스는 저장·공유 수가 알고리즘 도달을 좌우하는데, 사람들은 **명시적으로 시켜야** 한다. 이미지만 올리지 말 것.

## bio 링크 — 클릭 테스트 필수

bio 링크는 **`marklens.site/ig`** 사용 (→ 구독 페이지 직행 + 인스타 유입 UTM 추적).
교체 후 **본인 폰에서 직접 눌러** 구독 페이지로 한 번에 가는지 확인. 들어오는 모든 사람이 거치는 길이라 여기서 막히면 앞 작업이 다 샌다.

## KPI (측정) — ⚠️ 첫 2주는 일희일비 금지

- 인스타 알고리즘이 계정 주제를 학습하는 데 **게시물 10~15개**가 쌓여야 함. 초반 도달 저조는 콘텐츠 문제가 아니라 정상 과정.
- **2주 차부터의 추세**(저장·공유·프로필 방문)를 본다. 첫 주 조회수로 "역시 안 되네" 하는 게 가장 흔한 포기 패턴 — 거기 빠지지 말 것.
- 인스타: 게시물별 도달·저장 (어드민 분석 → 인스타그램 패널)
- 전환: GA4 `newsletter_subscribe` 이벤트의 location별 (어느 경로가 구독으로 이어지는지)
- 북극성: **이메일 구독자 수** (팔로워보다 우선)
