# MarkLens A2 — Editorial Hybrid

Canonical v3 approved on 2026-10-10. The four SVGs in `public/brand/`
are the source of truth: primary, reverse, signal and compact M1.
Do not replace their paths with font-rendered text or reconstruct them again.
`source-manifest.json` records their SHA256 checksums.

- Electric Blue: `#164BFF`.
- Minimum wordmark width: 120px. Compact minimum: 16px.
- Header: primary on light surfaces, reverse on dark surfaces; no signal period.
- Clear space: approximately half the wordmark height.
- Weekly uses the unchanged master with an editorial descriptor. Its exported
  descriptor uses fixed Pretendard outlines, not a replacement master wordmark.

Run `node tools/export-brand-assets.mjs` from the repository root to regenerate
PNG exports, the multi-resolution ICO and the Satori path component. This command
does not alter canonical geometry. Website images reference the static SVGs;
email uses PNG exports; OG and V2 social renders use the same fixed path.

No PWA manifest is installed. The Apple icon is used by existing metadata.
The Instagram 1080px export is a deliverable only; no upload is performed.
Existing legacy cardnews rendering remains unchanged.

The rejected v2 reconstruction and the approved raster remain historical
references in the original local A2 review packages, outside runtime assets.
