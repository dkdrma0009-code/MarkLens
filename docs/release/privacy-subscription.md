# 개인정보·구독 출시 준비 (R-2)

이 문서는 법적 문구를 확정하지 않는다. `[운영자 확인 필요]`·`[법률 검토 필요]` 항목이 채워지기 전에는 공개 페이지에 고지를 게시하지 않으며, 기존 구독 기능은 그대로 유지한다. **출시 전 필수 해결 과제(P1)**다.

R-3: 고지 UI와 처리방침 초안은 [privacy-policy-draft.md](privacy-policy-draft.md)에 있다(미적용, 빈칸은 운영자 확인 필요).

## 1. 현재 수집 흐름 (코드 기준)

| 단계 | 내용 | 위치 |
|---|---|---|
| 수집 | 이메일 1개 항목, 유입 위치(`source`) | 구독 폼: `NewsletterInlineCta`(홈·상세 하단 등), `/newsletter` 페이지 |
| 저장 | `subscribers`: email, status, source, subscribed_at, confirmation_token·expires_at·confirmed_at, drip_step, unsubscribed_at (IP·기기 정보 없음) | Supabase(서울 리전 여부 `[운영자 확인 필요]`) |
| 확인 | 이중 확인(double opt-in): 48시간 유효 토큰 메일 → 확인 시 `active` | `/api/subscribe`, `/api/confirm-subscription` |
| 중복 | 이미 구독 중이면 "이미 구독 중" 안내, 기존 행 유지 | `issue_subscription_confirmation` |
| 발송 | 확인·환영·온보딩 드립·주간 뉴스레터 — Brevo(프랑스, EU) | `lib/newsletter/*`, `api/newsletter/send` |
| 해지 | 메일 하단 링크 → `status=unsubscribed`, `unsubscribed_at` 기록. **행과 이메일은 삭제되지 않음** | `/api/unsubscribe` |
| 방문 측정 | GA4(`gtag`) — 운영 도메인에서만, 관리자 제외. 쿠키 사용. 동의 배너 없음 | `lib/analytics.ts` |
| AI 한도 | 비로그인 사용자는 IP 해시(32자, 원문 IP 미저장)를 하루 단위 카운터 키로 사용 | `lib/ai/budget.ts`, `ai_usage` |

## 2. 누락된 고지 항목

구독 폼 바로 아래(또는 체크박스 동의) 최소 고지:
1. 수집 항목: 이메일 주소
2. 이용 목적: MarkLens 뉴스레터·서비스 안내 발송
3. 보유·이용 기간: `[운영자 확인 필요]` — 현재 코드는 해지해도 삭제하지 않는다. 해지 시 즉시 삭제 또는 N일 후 파기 중 결정이 필요하고, 결정에 맞춰 해지 처리 코드를 바꿔야 한다.
4. 동의 거부권과 불이익: 거부할 수 있으며, 거부하면 뉴스레터를 받을 수 없음
5. 광고성 정보 수신 동의 여부: `[법률 검토 필요]` — 뉴스레터가 광고성 정보에 해당하는지에 따라 별도 동의·(광고) 표기·야간 발송 제한이 필요하다.
6. 개인정보처리방침 링크

## 4. 최소 UX 변경안 (적용 전)

- 구독 입력창 아래 한 줄(12px 이상, 본문 대비 4.5:1 이상): "이메일은 MarkLens 뉴스레터 발송에만 사용하며, 구독 해지 시 [보유 기간] 후 파기합니다. [개인정보처리방침]"
- 광고성 정보 동의가 필요하다는 검토 결과가 나오면: 필수 체크박스 "개인정보 수집·이용 동의(필수)" + 미체크 시 제출 비활성화. 구독 API 계약(`email`, `source`)은 그대로 두고 동의 시각만 추가 저장하는 방안을 검토한다(스키마 변경 필요 — 별도 마이그레이션).
- 처리방침 페이지 `/privacy`(푸터 링크). 내용은 3장이 채워진 뒤에 게시한다.
- 적용 위치는 구독 폼 컴포넌트 2개뿐이다(`NewsletterInlineCta`, `/newsletter`의 `NewsletterClient`).

## 5. 출시 판단

- 운영자 정보와 보유 기간이 정해지기 전에는 **새 Production 배포의 출시 조건 미충족**으로 본다.
- 기존 운영 사이트의 구독은 이미 같은 상태로 운영 중이므로 즉시 중단하지 않는다(무단 비활성화 금지). 대신 가장 빠른 배포에서 고지를 함께 반영한다.
