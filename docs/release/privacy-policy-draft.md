# 개인정보 고지·처리방침 초안 (R-3, 미적용)

**상태: 초안. 공개 페이지에 적용하지 않았다.** `[운영자 확인 필요]`·`[법률 검토 필요]`는 임의로 채우지 않는다. 운영 주체·연락처·보유 기간이 정해지고 검토가 끝난 뒤 적용한다. 현재 운영 중인 구독 기능은 바꾸지 않는다. 배경과 수집 흐름은 [privacy-subscription.md](privacy-subscription.md)에 있다.

## A. 구독 폼 고지 UI 초안

적용 위치는 두 곳이다. 둘 다 폼 아래에 있는 기존 안내 문단 바로 다음에 한 줄을 추가한다.
- `src/components/NewsletterInlineCta.tsx`(홈·상세 하단 등)
- `src/app/(public)/newsletter/NewsletterClient.tsx`(`#weekly-note`)

표시 원칙:
- 기존 `ml-form-note` 스타일(12px 이상)을 재사용하고 본문 대비 4.5:1 이상으로 한다.
- 레이아웃·버튼·입력창은 그대로 둔다(디자인 변경 없음).

**A-1. 광고성 정보 동의가 필요 없다는 검토 결과일 때 — 안내 한 줄**

```
이메일 주소는 MarkLens 뉴스레터 발송에만 쓰며, 구독을 해지하면 [보유 기간 — 운영자 확인 필요] 안에 파기합니다. 자세한 내용은 개인정보처리방침에서 확인할 수 있습니다.
```
- "개인정보처리방침"은 `/privacy` 링크다.
- 입력창의 `aria-describedby`에 이 문단 id를 추가한다(스크린리더가 함께 읽도록).

**A-2. 별도 동의가 필요하다는 검토 결과일 때 — 체크박스** `[법률 검토 필요]`

```
[ ] (필수) 개인정보 수집·이용에 동의합니다 — 항목: 이메일 / 목적: 뉴스레터 발송 / 보유: 해지 후 [기간]  [자세히]
[ ] (필수 또는 선택 — 검토 결과) 광고성 정보 수신에 동의합니다
```
- 필수 항목에 체크하지 않으면 제출 버튼을 비활성화하고, 그 이유를 버튼 아래에 문장으로 보여준다.
- 동의 시각을 저장하려면 `subscribers`에 컬럼을 추가해야 한다(별도 마이그레이션 — 이번 범위 아님). 구독 API 계약(`email`, `source`)은 유지하고 필드만 추가한다.
- 광고성 정보에 해당하면 메일 제목의 `(광고)` 표기와 야간(21시–8시) 발송 제한을 검토한다. 현재 발송 시각은 월요일 7:30이므로 해당 여부 확인이 필요하다 `[법률 검토 필요]`.

## B. 개인정보처리방침 초안 (`/privacy`)

> 시행일: [게시일 — 운영자 확인 필요]

**1. 처리하는 개인정보와 목적**

| 서비스 | 항목 | 목적 | 보유 기간 |
|---|---|---|---|
| 뉴스레터(Weekly) | 이메일 주소, 구독 경로(페이지 위치), 구독·확인·해지 시각 | 구독 확인, 뉴스레터·온보딩 메일 발송 | `[운영자 확인 필요]` — 현재 코드는 해지 후에도 삭제하지 않음(아래 C-1) |
| Insight Lab 로그인 | 이메일 주소(로그인 계정), 분석 답변·노트·학습 기록 | 로그인, 기록 저장, 성장 리포트 | `[운영자 확인 필요]` — 계정 삭제 시 함께 삭제(DB `ON DELETE CASCADE`) |
| AI 기능(챗, 면접 연습, 학습, Insight Lab) | 사용자가 입력한 문장 | 답변·피드백 생성 | MarkLens는 입력 원문을 저장하지 않음 `[운영자 확인 필요 — 경로별 재확인]`. 외부 AI 제공자 보유 정책은 4항 |
| AI 사용량 제한 | 접속 IP의 해시값(원문 IP 미저장), 로그인 사용자 id | 과도한 사용 방지 | 일 단위 카운터 `[보관 기간 — 운영자 확인 필요]` |
| 의견 보내기 | 평가, 좋았던 점·아쉬운 점, 직무, 구독 의향(이메일·이름 없음) | 서비스 개선 | `[운영자 확인 필요]` |
| 방문 통계(Google Analytics 4) | 쿠키, 기기·브라우저 정보, 방문 페이지 | 이용 통계 | Google 정책 및 설정 기간 `[운영자 확인 필요]` |

**2. 동의 거부권** — 개인정보 제공을 거부할 수 있다. 거부하면 해당 서비스(뉴스레터 수신, Insight Lab 기록 저장)를 이용할 수 없다. 사이트 열람은 거부와 무관하게 가능하다.

**3. 제3자 제공** — 하지 않는다. `[운영자 확인 필요]`

**4. 처리 위탁·국외 이전**

| 수탁자 | 업무 | 이전 국가 | 항목 |
|---|---|---|---|
| Supabase | 데이터베이스·로그인 | `[리전 — 운영자 확인 필요]` | 1항 전체 |
| Vercel | 웹 호스팅 | 미국 등 | 접속 기록 |
| Brevo | 메일 발송 | EU(프랑스) | 이메일 주소 |
| Google(Analytics, Gemini) | 방문 통계, AI 응답 생성 | 미국 | 쿠키 정보, AI 입력 문장 |
| Anthropic, OpenAI | AI 응답 생성(대체 경로) | 미국 | AI 입력 문장 |

- 이전 일시·방법(서비스 이용 시 네트워크 전송), 보유 기간, 거부 방법은 `[법률 검토 필요]`.
- AI 제공자의 데이터 보유·학습 사용 여부는 각 사의 API 약관과 계약 설정으로 확인 `[운영자 확인 필요]`.

**5. 파기** — 보유 기간이 끝나거나 목적을 달성하면 지체 없이 파기한다. 전자 파일은 복구할 수 없는 방법으로 삭제한다. 절차·주기는 `[운영자 확인 필요]`.

**6. 정보주체의 권리** — 열람·정정·삭제·처리정지를 요구할 수 있다.
- 뉴스레터: 메일 하단 "구독 해지" 링크.
- 그 밖의 요청: `[연락처 — 운영자 확인 필요]`.

**7. 쿠키** — 방문 통계를 위해 Google Analytics 쿠키를 쓴다. 브라우저 설정에서 거부할 수 있다. 관리자 브라우저는 측정에서 제외된다. 동의 배너는 없다 `[법률 검토 필요]`.

**8. 안전성 확보 조치** — 다음 조치를 적용한다.
- 전송 구간 암호화(HTTPS)
- 데이터베이스 접근 권한 분리(RLS, 서버 전용 키)
- 관리자 인증
- 구독 이중 확인
- 원문 IP 미저장

**9. 개인정보 보호책임자** — `[성명·직책·연락처 — 운영자 확인 필요]`

**10. 변경** — 변경 시 시행 7일 전에 이 페이지로 알린다. `[법률 검토 필요]`

## C. 결정 후 필요한 코드 변경 (이번 범위 아님)

1. **해지 시 처리:** 결정한 보유 기간에 맞춰 바꾼다.
   - 현재 `/api/unsubscribe`는 `status=unsubscribed`만 기록한다.
   - 즉시 삭제로 정하면 행을 지운다(재구독 시 새 행).
   - 기간 후 파기로 정하면 정기 삭제 작업을 추가한다.
2. **`/privacy` 페이지와 연결:** B를 확정한 뒤 `/privacy` 페이지를 만들고, 푸터와 두 구독 폼에 링크를 단다.
3. **동의 시각 저장:** A-2를 채택하면 `subscribers`에 동의 시각 컬럼을 추가하는 마이그레이션과 API 필드를 추가한다.
4. **AI 입력 저장 여부 재확인:** 경로별(면접 리포트, Insight Lab 평가)로 입력 원문이 DB에 남는지 확인해 1항을 확정한다. Insight Lab은 답변을 `insight_sessions`에 저장한다.
