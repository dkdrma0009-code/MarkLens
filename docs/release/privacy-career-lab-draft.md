# 개인정보처리방침 보완 초안 — Career Lab (P9B)

> P9D에서 공식 법령과 작성지침을 대조해 수정안을 구현했다. 현재 기준은 `p9d-privacy-review.md`이고, 이 문서는 이력으로 남긴다.

**상태: 초안. 공개 방침에 반영하지 않았다.** `src/components/legal/PrivacyPolicy.tsx`와 `PRIVACY_FACTS.effectiveDate`는 변경하지 않았다. 시행일은 실제 배포일이 정해진 뒤 운영자가 확정한다. 문구는 운영자·법률 전문가 검토 대상이다.

## 1. 코드로 확인한 사실 (`release/career-lab-rc2`)

| 대상 | 수집·서버 전송 | 외부 전송 | 브라우저 내 처리 | DB 저장 |
|---|---|---|---|---|
| 면접 답변 | AI 피드백·종합 평가 요청 시 서버 경유 (`/api/interview/feedback`, `/report`) | Google Gemini, 장애 시 Anthropic·OpenAI | 화면 상태로 유지 | 저장 안 함 |
| 기업명·직무·채용공고·자기소개서·포트폴리오 | 맞춤 질문 요청 시 서버 경유 (`/api/interview/custom-questions`). 항목별 글자 수 제한 | 위와 같음 | 입력 폼 상태로 유지 | 저장 안 함 |
| 카메라 영상, 선택 시 소리 | 없음 (업로드 코드 없음) | 없음 | MediaRecorder Blob. 화면을 떠나거나 다시 시작하면 해제 | 저장 안 함 |
| 음성 답변 | MarkLens로는 받아 적힌 글만, 답변과 같은 경로 | 브라우저 음성 인식(Web Speech API). 브라우저에 따라 음성이 브라우저 제공자의 서버로 전송될 수 있음 | 브라우저 기능 | 저장 안 함 |
| 내려받은 녹화 파일 | 없음 | 없음 | 이용자 기기에 저장, 이용자가 직접 삭제 | 저장 안 함 |
| AI 사용량 제한 | IP 해시 또는 회원 식별자 | Supabase 보관 | — | 90일 후 자동 삭제 |

- 답변 내용을 기록하는 로그 코드는 Career Lab 경로에 없다. localStorage 등 브라우저 저장소도 쓰지 않는다.
- 음성 인식 근거: MDN은 Chrome 등에서 음성이 웹 서비스로 전송된다고 설명하고, Web Speech 명세는 `processLocally`가 기본값(false)이면 음성이 원격 서버로 갈 수 있다고 적는다. 코드는 이 값을 설정하지 않는다.
- AI가 중지된 동안에도 맞춤 질문 요청 본문은 Vercel 서버까지는 도달한다(서버가 내용을 읽기 전에 503으로 거절하며, 외부 AI로 가지 않는다). 아래 문구는 AI 켜짐·꺼짐 모두에서 참이 되도록 썼다.

## 2. 수정안

**`rows`의 AI 기능 행, 항목 칸**

> 사용자가 입력한 문장. 맞춤 면접을 이용하면 입력한 기업명·직무·채용공고·자기소개서·포트폴리오와 면접 답변

**`rows`에 추가할 행** (서비스 / 항목 / 목적 / 보유 기간)

| 서비스 | 항목 | 목적 | 보유 기간 |
|---|---|---|---|
| 면접 연습의 카메라 녹화(선택) | 수집하지 않습니다. 영상과, 선택한 경우의 소리는 이용자의 브라우저 안에서만 처리되며 MarkLens 서버로 전송되지 않습니다. | 이용자 본인의 답변 확인 | 화면을 떠나거나 탭을 닫으면 브라우저에서 사라집니다. 내려받은 파일은 이용자 기기에 남고 이용자가 직접 삭제합니다. |
| 면접 연습의 음성 답변(선택) | MarkLens는 음성을 받지 않으며, 브라우저가 받아 적은 글만 입력한 답변과 같게 처리합니다. | 말한 내용을 답변 글로 입력 | 위 AI 기능 행과 같습니다. |

**`processors` 표의 Google·Anthropic·OpenAI 행, 항목 칸**

> AI 기능에 입력한 문장(맞춤 면접의 기업명·직무·채용공고·자기소개서·포트폴리오와 면접 답변 포함)

**1절 표 아래에 추가할 문단**

> 면접 연습의 음성 답변은 이용자가 사용하는 브라우저의 음성 인식 기능을 이용합니다. Chrome 등 일부 브라우저는 음성을 브라우저 제공자의 서버로 보내 처리할 수 있으며, 이 처리는 해당 브라우저 제공자의 개인정보 처리 방침을 따릅니다. 원하지 않으면 음성 답변을 켜지 않고 글로 답할 수 있습니다.
>
> 맞춤 면접 입력란에는 주민등록번호, 건강 정보처럼 면접 준비에 필요하지 않은 정보를 넣지 마세요.

## 3. 반영 절차 (승인 후)

1. 위 문구를 `PrivacyPolicy.tsx`에 반영하고 `docs/release/privacy-policy-draft.md`와 맞춘다.
2. 운영자가 실제 배포일로 `PRIVACY_FACTS.effectiveDate`를 정하고, 이를 고정한 `tests/privacy-notice.test.mjs`를 함께 갱신한다.
3. 방침 변경 전 버전의 보존과 변경 고지 방법을 운영자가 정한다.

## 4. 전문가 검토 항목 (이번 단계에서 공식 근거를 확인하지 못함)

`law.go.kr`과 개인정보보호포털은 본문 없이 응답해 법령 원문을 확인하지 못했다. 코드 주석의 조문(법 제28조의8 제2항, 제30조제1항제6호)은 별도로 검증하지 않았다. 찾기쉬운 생활법령정보는 「개인정보 보호법」 2027년 3월 9일 시행본을 표시한다(2026-10-15 기준).

- 2027-03-09 시행 개정 사항이 처리방침 기재 항목에 미치는 영향
- 브라우저 제공자의 음성 처리가 위탁·제3자 제공에 해당하는지, 고지로 충분한지
- 맞춤 면접 입력의 외부 AI 전송에 대한 고지·동의 요건과 국외 이전 요건
- 자기소개서에 포함될 수 있는 민감정보·고유식별정보, 제3자 정보의 처리
- 외부 AI 공급자의 보유 기간과 학습 사용 여부(API 약관 확인 필요)를 방침에 어떻게 적을지
