# Career Lab 실기기 QA 체크리스트 (P9D)

**대상:** 최종 RC Preview. 아래 "미실행"은 사람이 실제 기기에서 해야 한다. 실행 후 결과와 기기 이름을 적는다. 자동 결과는 실제 장치 동작을 증명하지 않는다.

## 직접 확인할 항목

준비: 최종 RC Preview 주소로 접속하고, 민감한 내용 없이 합성 답변만 사용한다.

| # | 기기 | 절차 | 기대 결과 | 결과 |
|---|---|---|---|---|
| 1 | Windows Chrome 카메라 | 일반 면접 → 카메라 켜기 → 권한 허용 → 3문항 답변 | 켤 때만 권한을 묻고, 미리보기와 녹화 표시가 나온다 | 미실행 |
| 2 | 〃 | 면접 중 카메라 끄기 | 카메라 표시등이 꺼지고 면접은 계속된다 | 미실행 |
| 3 | 〃 | 결과 화면에서 녹화 파일 내려받아 재생 | 답변별 파일이 재생되고 파일 이름과 확장자가 맞다 | 미실행 |
| 4 | 〃 | "녹화에 소리 포함"을 켜고 녹화 후 재생 | 소리가 들리고 결과에 소리 포함으로 표시된다 | 미실행 |
| 5 | Windows Chrome 마이크 | 음성 답변 켜기 → 말하기 | 실제 말이 글로 나오고 듣는 중에는 입력란이 읽기 전용이다 | 미실행 |
| 6 | 〃 | 10초 침묵, 음성 답변 끄기, 면접 종료 | 계속 듣다가 끄면 편집 가능해지고, 종료 후 마이크 표시가 꺼진다 | 미실행 |
| 7 | 〃 | 사이트 권한에서 카메라·마이크 차단 후 켜기 → 안내 확인 → 허용으로 변경 → 다시 시도 | 차단 중에도 글로 계속할 수 있고 허용 후 다시 시도가 된다 | 미실행 |
| 8 | 〃 | 면접 중 새로고침, 메뉴 이동, 뒤로 가기, 탭 닫기 | 새로고침과 메뉴 이동은 확인을 묻는다. 뒤로 가기는 묻지 않는 것이 알려진 동작이다. 떠난 뒤 카메라와 마이크가 꺼진다 | 미실행 |
| 9 | iPhone Safari | 일반 면접을 모든 장치 꺼짐으로 완료 | 글 답변으로 결과까지 간다 | 미실행 |
| 10 | 〃 | 카메라 켜기 → 녹화 → 내려받기 | 안 되면 안내가 나오고 면접은 계속된다. 되면 파일이 재생된다 | 미실행 |
| 11 | 〃 | 음성 답변 켜기 | 지원되면 글로 나오고, 안 되면 안내 후 글로 계속할 수 있다 | 미실행 |
| 12 | 〃 | 권한 거부 후 iOS 설정에서 허용하고 다시 시도 | 안내대로 복구되고 면접 내용이 사라지지 않는다 | 미실행 |
| 13 | 〃 | 답변 입력 중 화면 키보드 표시, 가로·세로 회전 | 입력란과 제출 버튼을 쓸 수 있고 가로 스크롤이 없다 | 미실행 |
| 14 | 〃 | 면접 중 다른 앱으로 전환했다가 복귀, 화면 잠금 | 멈추거나 내용이 사라지면 결함으로 적는다 | 미실행 |
| 15 | 〃 | 학습 퀴즈 객관식 5문제 완료, `/privacy` 표 좌우 스크롤 | 끝까지 풀 수 있고 표를 읽을 수 있다 | 미실행 |
| 16 | 접근성 | Windows 내레이터 또는 NVDA로 설정 → 질문 → 결과 | 질문, 상태, 결과가 읽히고 포커스가 이동한다 | 미실행 |
| 17 | 접근성 | iPhone VoiceOver로 시작 → 첫 질문 답변 | 버튼 이름과 질문이 읽힌다 | 미실행 |
| 18 | 접근성 | 키보드만으로 Chrome에서 면접 완료 | 모든 조작이 가능하고 포커스가 보인다 | 미실행 |

결함이 나오면 기기, 브라우저 버전, 순서, 화면을 적는다. 답변이나 녹화 파일은 공유하지 않는다.
