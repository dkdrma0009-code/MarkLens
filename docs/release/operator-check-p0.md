## 1. `/admin` 첫 화면

화면 위쪽 날짜가 `… / KST`로 표시됩니다. 숫자는 그날(한국 시간) 기준입니다.

| 화면 문구 | 적을 것 | 뜻 |
|---|---|---|
| Today collected · 오늘 수집 | 숫자 | 오늘 새로 들어온 기사. 오전 10시 이후에도 0이면 예약 수집이 안 돌았거나 실패 |
| Today new insights · 오늘 신규 생성 | 숫자 | 오늘 분석이 끝난 기사. 수집은 있는데 0이면 분석 단계 실패 |
| Current ready · 현재 분석 완료 재고 | 숫자 | 분석은 됐지만 아직 공개 전. 0보다 큰데 공개가 없으면 공개 단계 문제 |
| Today site published · 자동 사이트 발행 기록만 | 숫자 | 오늘 자동 공개된 기사 |
| Pending · 검수 대기 / Analyzing · 분석 상태 | 각 숫자 | 분석 대기 / 분석 중. "분석 상태"가 몇 시간 넘게 0이 아니면 실행 도중 강제 종료 |
| 연동 상태 (실시간) → Brevo 메일 | 정상/오류 + 오류 문구 | 메일 발송 키가 살아 있는지. 계정 이메일이 함께 보이면 그 부분은 적지 않음 |

## 3. 경보 수신 주소 확인 (발송 없이)

`/admin/newsletter` → **"실제 테스트 메일"** 버튼 → 확인 창 설명의 **"발송 대상: …"** 이 관리자 경보가 가는 주소입니다(둘 다 `ADMIN_EMAIL`). 확인한 뒤 **반드시 "취소"(또는 오른쪽 위 X)**. 확인 버튼을 누르면 실제 메일이 나갑니다.
이 주소가 평소 확인하는 메일함인지(Gmail / 네이버 / `newsletter@marklens.site` 같은 사이트 주소)만 알려 주세요.
`newsletter@marklens.site`는 10/25부터 ImprovMX를 거쳐 네이버 관리자 메일로 전달됩니다. 그 전에는 이 주소로 오는 메일이 어디에도 도착하지 않았습니다(`privacy-operations.md`).

## 5. Brevo (메일 발송 서비스)

app.brevo.com → 거래 메일(Transactional) 메뉴의 **로그(Logs)** 에서 제목 `[MarkLens 알림]` 기록을 찾습니다. 메뉴 이름은 계정 언어·버전에 따라 다를 수 있습니다.
기록이 있으면 날짜와 상태(전달됨 Delivered / 반송 Bounced / 차단 Blocked / 오류)를 적습니다. 차단된 연락처(Blocked contacts) 목록에 3번 주소가 있는지도 봅니다.

| Brevo 기록 | 뜻 |
|---|---|
| `[MarkLens 알림]` 기록이 아예 없음 | 경보 함수가 호출되지 않았거나(실행 중단·조건 미충족) 발송 설정이 비어 조용히 끝남 |
| 기록이 있고 반송·차단·오류 | 발송을 시도했지만 실패. 반송이 한 번 나면 Brevo가 그 주소를 이후에도 차단할 수 있음 |
| 기록이 있고 전달됨, 받는 주소가 확인한 메일함과 다름 | 다른 계정으로 갔음 |
| 기록이 있고 전달됨, 같은 메일함인데 검색 안 됨 | 메일함 필터·분류·전달 단계(ImprovMX) 문제 |
